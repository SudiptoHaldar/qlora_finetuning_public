## What was implemented

- **Command files.** `generate-prp` and `execute-prp` now read the two planning guides
  instead of an absent EDGAR guide, run Python as `venv\Scripts\python -m <tool>`, state the
  1000-line guideline, and use "run the changed script once" as the manual gate. `execute-prp`
  also carries the rules that billed steps belong to the owner and every AWS command is logged.
  `release-tag` no longer mentions a package version. `wip-roll` reports "Project status"
  (milestones, spend against the cap in `config/aws.yaml`, operator-gated steps);
  `roadmap_view-roll` uses matching examples.
- **Templates.** `prp_base.md` and `prp_lean.md` use venv commands, project paths, and a
  synchronous pseudocode example with an injected client; the web-service, `curl`, and `mypy`
  lines are gone. `GUIDELINES.md` examples are this project's.
- **`coding.md`.** Correct plan path; the eight sub-packages plus `scripts/` and `config/`;
  the venv rule in both forms; the test rule for GPU, network, credentials, and paid calls;
  new rules for secrets and for logging AWS commands.
- **Database stack.** `alembic.ini` and the empty `alembic/` folder deleted; six pins removed
  from `requirements.txt`; `DATABASE_URL` removed from `.env.example`; the `db` marker removed.
- **References.** `README.md`, `common/gotchas.md` (32 entries in four groups, each with its
  source and whether it is confirmed), `common/troubleshooting.md`, `tech/boto3.md`,
  `project_patterns/README.md`, and an empty `patterns/`.
- **Tracking folders.** `track_progress/wip/` and `track_progress/roadmap_views/`.

## Differences from the spec

- **Scan pattern narrowed**, as the spec allowed: `registry` and `pypi` match only in their
  publication senses, because "run registry" and "PyPI pins" are correct here. The pattern also
  gained `pyproject`, `tooltip`, `ticker`, `mypy`, `curl`, `src/`, and `paypal`.
- **Inherited example names replaced** in `generate-prp.md` (`req_026_paypal_integration` and
  similar) with names from this repository. Formats and naming rules are unchanged.
- **The scan is also a test**, `tests/test_process_scaffold.py`, so inherited content cannot
  return unnoticed.
- **A few web-service leftovers outside the spec's list were also replaced** in
  `GUIDELINES.md` and `prp_base.md` (CRUD, endpoint, route, ORM, and async examples).
