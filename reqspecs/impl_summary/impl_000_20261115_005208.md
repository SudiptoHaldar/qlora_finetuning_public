## What was implemented

- **`requirements-train.txt`**: ten exact pins. torch is listed without an index URL; the CUDA
  build is installed first by a runbook command.
- **`config/local_env.yaml`**: minimum Python, the CUDA build tag, minimum VRAM, the BF16
  capability floor, and the smoke model, revision, LoRA, and quantization settings.
- **`qlora_finetuning/environment.py`**: `read_pins`, `installed_versions`, `version_matches`
  (accepts a local build suffix such as `+cu126`), and `environment_report`, a plain dict of
  versions and GPU facts that never raises.
- **`scripts/env_check.py`**: six offline checks and the opt-in smoke. A check whose
  prerequisite failed is shown as SKIP. `--report` writes the report and results as JSON.
- **Guard test**: no file in `qlora_finetuning/`, `scripts/`, or `tests/` imports a training
  library at module level.

## What the run established

- **Q3 is resolved: native Windows.** bitsandbytes 0.50.2 loads a model in 4-bit, generates,
  trains a LoRA step, and runs the 8-bit paged AdamW on this machine. WSL2 is not needed.
- **Thinking mode**: on by default. `enable_thinking=False` appends an empty `<think>` block to
  the prompt, after which the model answers directly. Training targets must follow that block.
- **TRL 1.18.0** has no `DataCollatorForCompletionOnlyLM`. `SFTConfig` offers
  `completion_only_loss` and `assistant_only_loss`, and its length field is `max_length`.
- **transformers 5.23** deprecates `gradient_checkpointing_enable`; peft 0.21.3 still calls it,
  producing two harmless warnings.

## Differences from the spec

- **E7 wording.** The spec said the chat template "produces no thinking block". The template
  itself adds an empty one to the prompt, so the check looks at the generated output.
- **E7 also checks that the optimizer step changed a LoRA weight**, and that no frozen base
  tensor received a gradient.
- **`main()` accepts a prepared environment**, so unit tests never inspect the real machine.
- **Noisy HTTP loggers are held at WARNING** during a run.
