## What was implemented

- **Pin.** `config/data.yaml` names `bevaya/FinQA` at commit
  `3d6a736bc67e06bc15fbf3618d88204a57c5b25e` and gives each of the three Parquet files its
  SHA-256, size, and row count, plus the facts the data is expected to show. A revision that is
  not a full commit hash is rejected.
- **Snapshot.** `fetch_snapshot` downloads the missing files into
  `artifacts/data/finqa/<commit>/` through a downloader passed as an argument (the default
  uses `huggingface_hub`), verifies all of them, and writes `snapshot.json`. It never deletes
  a file, and leaves a present-but-wrong file alone unless forced. `verify_snapshot` checks
  presence, size, checksum, and row count.
- **Raw reader.** `load_raw_examples()` verifies first, then returns 8,281 `RawExample`
  records in the order train, validation, test, with plain Python values, `gold_inds` parsed
  into a dict, and company, year, page, and index read from the id. Nothing is dropped or
  repaired.
- **Schema report.** `build_report` counts columns, ids, groups, duplicates, tables, evidence,
  programs, and answers, in total and per official split, lists the ids of 23 classes of odd
  example, and runs ten checks against the config. Output is JSON and Markdown under
  `reports/data/`, with counts and ids only and no timestamp.
- **Scripts.** `python -m scripts.finqa_fetch` (`--verify-only`, `--force`) and
  `python -m scripts.finqa_report` (`--check`), with exit codes 0, 1, 2.

## Differences from the spec and the PRP

- **`pandas` is not used.** `pyarrow`'s `to_pylist()` returns plain lists and dicts, which is
  what the spec's D8 asks for, with no conversion step. D6 in the spec was amended.
- **One figure corrected.** Spec section 2.4 said 5,170 examples with table evidence only and
  1,172 with both. The report gives 5,171 and 1,171: the first profile counted the malformed
  key `text_-1` as text evidence. Every other figure in spec section 2 was reproduced.
- **Synthetic snapshots are checked against their own expected inventory.** Checks S7–S9
  require the seen sets to equal the expected sets, which five invented rows cannot do against
  the real inventory.
- **`coding.md` gained two rules** that the spec did not list, because they bind every later
  version.

## Issues resolved

- The Hub library prints a warning that no token is set. The dataset is public and the spec
  says no token is used, so `finqa_fetch` holds that logger at ERROR.
- Year values were printed with a thousands separator (`1,999`); the Markdown now prints years
  plainly.
- Field names lost their underscores in Markdown labels (`Exe ans`); labels now keep
  `exe_ans`, `gold_inds`, and `table_ori` as written.
