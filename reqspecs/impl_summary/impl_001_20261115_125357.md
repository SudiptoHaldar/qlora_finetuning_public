## What was implemented

- **The rule.** Examples are grouped by company. Groups are ordered by the SHA-256 of
  `"<seed>:<salt>:<company>"` and taken while they fit under the target, so there is no random
  generator anywhere. Dev is carved from the training side the same way; quick-dev is the
  first 200 dev examples in digest order of their id.
- **The manifest.** `splits/finqa_split_manifest.json` holds the dataset pin, the settings,
  the company-to-split and id-to-split tables, the quick-dev ids, the counts, and a content
  hash. `write_manifest` writes it when absent, accepts an identical one, and refuses to
  replace a different one. There is no force option.
- **Loaders.** `load_split("fit" | "dev" | "quick_dev")` first checks that the manifest
  describes exactly the data on disk, then returns the records in dataset order.
  `split_ids(name)` and `manifest_hash()` need no data.
- **Test lock.** `load_split("test")` raises `TestLockedError` before any data is read, unless
  `splits/test_unlock.json` exists and names the current content hash. This version does not
  create that file. Guard tests fail if it appears, and if any file outside the data package
  uses the raw reader.
- **Split report.** Counts per split (size, program length, operations, argument kinds,
  evidence kinds), a table of what the held-out side could have met on the other side, and
  checks P1 to P10. Counts only; no company symbols, no text, no timestamp.
- **Script.** `python -m scripts.finqa_split` and `--check`, exit codes 0, 1, 2.

## Differences from the spec and the PRP

- **Leakage figures re-measured.** The spec's table in section 2.3 had been produced with a
  plain cut rule, not the final fill rule, and counted header rows, whose "numbers" are years.
  On the final rule with unnamed rows excluded: report grouping 500 of 1,761 (28.4%, was
  28.6%); company grouping 0 of 1,861 (was 0 of 1,903); chance matches 58 (was 65). The
  conclusion is unchanged. The spec, roadmap, and execution plan now carry the new figures.
- **The report lists no company symbols.** Counts only; the manifest already lists which
  company is where.
- **The script exits 1, not 2, when the split cannot be built** from valid settings (for
  example a quick-dev size larger than dev), since that is a problem with the result, not with
  reading the config.

## Found while building

- **`exp` is nearly absent from training.** Of the dataset's 9 `exp` steps, 1 is in fit, none
  in dev, 8 in test. The seed is not re-rolled (spec D3). Recorded in the spec's limits and in
  `gotchas.md`.
