## Summary

The evaluation runner can now ask `Qwen/Qwen3-4B`, loaded in 4-bit on the local GPU.

- **Renderer** (`local_qlora/render.py`). `render_chat` wraps the canonical system and user
  texts in the chat template with thinking off and refuses a prompt that does not end with
  the thinking-off block. `read_generation` cuts a row of generated ids at its first end
  token and returns the text, the token count, and the stop reason; a complete thinking
  block at the start is removed and counted.
- **Backend** (`local_qlora/backend.py`). The only Path A module that loads the training
  stack. `load_backend` checks the stack, the cached weights, the tokenizer's fingerprint,
  and the GPU, then loads the pinned model in 4-bit NF4 from the local cache, optionally
  with a LoRA adapter (not merged, named in the settings by the hash of its weights).
  `generate` runs one left-padded batch greedily and stops only at an end token or the
  reply limit.
- **Predictor** (`local_qlora/predictor.py`). `QwenPredictor` over a backend that is passed
  in; measured token counts; any backend error becomes a `PredictorError` without text.
- **Runner and script.** A predictor's optional `measurements()` is stored in the run folder
  and shown in the summary under `backend`. `scripts/evaluate.py` offers `qwen3-4b` (path
  A, arm A0, local).

## Issues resolved

- **Unset generation values are filled from the model's sampling defaults.** In transformers
  5.23, a `GenerationConfig` passed to `generate()` has each `None` filled from the model's
  own config, which samples at temperature 0.6. The PRP's plan to pass `temperature=None`
  would not have unset anything. The backend replaces `model.generation_config` whole, and a
  `gpu` test checks that decoding is greedy and repeats.
- **Batch size 8 changed 16 of 40 replies** against batch size 1 (4 answer scores, no
  execution score), for 3.2 times the speed. By the spec's own rule the baseline was run at
  batch size 1 and the config stays there. The question returns to the owner.
- **A0 near zero was checked, not assumed.** The replies were read, the input tokens equal
  the token budget's to the token, and a repeat of 40 examples gave 40 identical replies.
- **The weights-absent check used an empty cache folder**, since the download had already
  started.
- A shell heredoc on this machine again mangled quoting and backslashes; edits to test files
  were made with script files instead.
