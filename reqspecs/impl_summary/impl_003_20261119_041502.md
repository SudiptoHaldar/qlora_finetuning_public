## Summary

- **Encoder** (`local_qlora/render.py`). `encode_example` turns a canonical record into the
  inference prompt, the reply, and the end token, with labels on the reply only. Its length
  is the token budget's. `encode_records` raises `LengthError` naming every record over the
  training length; nothing is cut.
- **Plan** (`local_qlora/plan.py`). Steps, warmup, checkpoint steps, and the worst batch,
  with the trainer's own arithmetic. The full run is 918 steps with 10 checkpoints.
- **Training** (`local_qlora/training.py`). `run_training` is one run in the registry: it
  probes the worst batch, trains with TRL's `SFTTrainer` on a prepared dataset
  (`max_length=None`, every argument from `config/training.yaml`), writes a log,
  measurements, and checkpoints, records a ledger line with training tokens also on a
  failure, and saves the final adapter with its metadata. Resuming is a new run from the
  last checkpoint, refused under other settings. A stand-in engine makes all of this
  testable without a model.
- **Adapters** (`local_qlora/adapters.py`). An adapter is named by its training run, or
  `RUN_ID/checkpoint-N`, and is refused if it was trained for another model commit, prompt
  wording, or split.
- **Scripts.** `scripts/qlora_train.py` (dry run, smoke run with checks K1 to K7, resume,
  stop after steps). `scripts/evaluate.py` gains `--adapter` and the entry `qwen3-4b-tuned`
  (arm A1); a smoke adapter runs under the name `qwen3-4b-tuned-smoke`.

## Issues resolved

- **Saving an adapter called the Hugging Face Hub.** PEFT asks the Hub for the base
  model's config when it saves. Training now sets the Hub to offline for the run; PEFT
  warns and saves correctly.
- **The step count is 918, not the spec's 916**: the trainer counts a last, smaller group
  of batches as a step. The plan mirrors the trainer, and a callback fails the run at once
  if the two ever disagree.
- **The trainer printed log entries to standard output.** Its printer and progress
  callbacks are removed.
- **A shell heredoc mangled quoting again**; edits were made with script files.

## Notes for the owner

- **Two runs with the same seed are not identical** (loss 0.953 against 0.971 at step 3).
  A rerun will not reproduce an adapter exactly.
- **GPU memory is close to the card's limit.** The worst batch reserves 12.35 GiB, and a
  resumed run reached 13.6. Close other GPU programs before a full local run; the probe
  will say in the first seconds if it does not fit.
- **Tuned inference is slower than the trial suggested**: about 5 seconds per example at
  batch size 1 in the partial evaluation, so about 40 minutes to score dev once.
- Nothing was committed. `.claude/settings.json` has a change that is not part of this
  version and was left as found.
