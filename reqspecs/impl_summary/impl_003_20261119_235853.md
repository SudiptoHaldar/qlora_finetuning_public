## Summary

- **Data bundle** (`qlora_finetuning/data/bundle.py`). `export_bundle` writes the raw
  examples of `fit` and `dev` and refuses anything else; every id is checked against the
  manifest's test ids on writing and on reading. With `QLORA_DATA_BUNDLE` set, `load_split`
  serves from the bundle, and the test split is refused whatever the unlock record says.
- **Job runner** (`local_qlora/job.py`, `scripts/job_run.py`). Tasks `smoke`, `train`,
  `evaluate` call `run_training` and `run_evaluation` unchanged. A task checks the installed
  libraries against the pins first and always writes `job_result.json`.
  `scripts/job_bootstrap.sh` is what the container runs: it links `artifacts/` and `ledger/`
  into the checkpoint folder, installs the pins, downloads the model, runs the task.
- **Launcher** (`local_qlora/sagemaker.py`, `staging.py`, `job_record.py`,
  `sagemaker_config.py`, `scripts/sagemaker_job.py`). `plan` builds the `CreateTrainingJob`
  request and runs checks J1 to J8, including a Path A cap of $100. `launch` (the owner's)
  uploads the code and the bundle with checksums, creates the job or adopts one that exists
  under the name, and writes the committed job record. `status`, `logs`, `stop`. `pull`
  brings a finished job's runs and adapters home, appends its ledger lines once, and
  records its billable seconds from `DescribeTrainingJob`. `rehearse` runs a task locally
  from the archive and the bundle.
- **Shared sign-in** (`qlora_finetuning/aws_common.py`), so that Path A and Path B need not
  import each other.
- **Config.** `config/sagemaker.yaml`; instance prices in `config/pricing.yaml`;
  `inference.batch_size: 8` in `config/local_qlora.yaml`.

## Issues resolved

- **Writing a bundle while the bundle variable is set** would have read the old bundle, not
  the snapshot. `export_bundle` now always reads the snapshot. A test found it.
- **The 256-character limit on an entry-point string** ruled out a `bash -c` script; the
  steps moved into a committed bootstrap script inside the archive.
- **Line endings.** `git archive` on this machine converts to Windows line endings; the
  archive is made with that switched off, and a test reads the script out of the archive.
- **The code was uncommitted during the build**, so `rehearse` can take the working tree's
  files, and says when it does.
- One Path B test patched `boto3` through the Bedrock module; it now patches the shared one.
