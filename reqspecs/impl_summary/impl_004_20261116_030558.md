## Summary

- **Export.** `export_files` renders fit as the training file and dev as the validation
  file: one Bedrock conversation per line with the canonical system, user, and target
  texts unchanged, which is the same texts in the same places as `BedrockProvider` sends
  for a question. Every record is exported, repeated ones too. Files go under git-ignored
  `artifacts/bedrock/<export id>/`; the id comes from the content.
- **Validation.** `validate_export` reads the files back from disk and runs X1 to X7: same
  records in order, no test id, the format, no reserved word (AWS's nine, any case, every
  text), AWS's limits, the current prompt and split, and that rendering again gives the
  same bytes. A failure names ids and words, never a text.
- **Estimate and gate.** `estimate_path_b` prices all of Path B with `Decimal`: the
  ledger's Path B tokens at list price, training (Qwen tokens times the Nova to Qwen ratio
  times the epochs, plus a 10% margin), the evaluation still to come, and storage. G1
  requires a ratio measured by the v4.01 baselines; G2 compares with the $200 cap. The
  committed gate record holds hashes, counts, and dollars.
- **Staging.** `stage_export` uploads with a SHA-256 checksum, reads back with
  `head_object`, and compares. It is the owner's (`--upload`).

Taken as recommended, because the owner started the PRP without changing them: 2 epochs,
a $200 cap for Path B, dev as the validation file.

## Issues resolved

- **Half a cent was shown rounded to the even cent** ($0.825 as $0.82). Amounts for reading
  now go through `usd()`, which rounds half up; stored amounts are exact text.
- **The first real run recorded no run.** Recording was tied to "files newly written", and
  an earlier `--check` had already written them. It is now tied to the gate record: an
  export is one run when its record is first written and one more when it is staged. The
  two record files of the first attempt were removed and the run repeated, so the ledger
  holds the export.
- **The estimate of the evaluation still to come** uses the reply limit for every reply
  ($9.32), where the spec's table assumed gold-length replies (about $6).
- **Four lint findings** (long lines), fixed.
