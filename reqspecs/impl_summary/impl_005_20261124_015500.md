## Summary

`python -m scripts.comparison_report build` reads the six test runs the six-arm record
names, rescored from their stored replies, and the cost record. It writes
`reports/comparison_report.md`, `reports/comparison/comparison_statistics.json` and `.md`,
`reports/comparison/accuracy_cost.svg`, and a block in `README.md`.

- **Intervals.** A paired percentile bootstrap, 10,000 resamples, one set of resampled
  questions for all arms. A second interval resamples the 43 companies of the test split.
- **Tests.** McNemar's exact test on six named pairs, adjusted together with Holm's method.
  A difference is "settled" only when its adjusted p-value and both intervals say so.
- **Errors.** The thirteen categories of v3.05 for all six arms, and accuracy by the number
  of gold steps.
- **The report** is filled from a template whose prose holds no figure. Its findings are
  generated sentences that follow the data.
- **No text is committed.** Written files hold counts and example ids. Example text is
  written by `examples` to the git-ignored `artifacts/` only.

## Issues resolved

- **The bootstrap needed too much memory** as first written (hundreds of megabytes for a
  chunk). It now counts how often each question is drawn and multiplies; the build takes
  about five seconds.
- **A sentence and its interval pointed opposite ways** ("B1-Pro is ahead of A1 by 2.00
  points, interval -3.31 to -0.66"). The sentence now turns the interval.
- **The figure's whiskers are hidden by the markers.** Its note now says so.
- **Two guard tests** failed after the first full run; see Test results.
- **A deviation named a folder that does not exist** (`req_001_data_pipeline`). A test now
  checks that every entry points at a file that exists.
