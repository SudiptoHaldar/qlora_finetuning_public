## Summary

`venv\Scripts\python -m scripts.hf_publish` has three commands:

- **`plan`** lists what would be uploaded and checks that each folder is the package that
  was checked. No network, no token.
- **`upload adapter --yes`** and **`upload merged --yes`** create the repository as private
  and upload the folder. Refused without `--yes`, without a token, when a file on disk
  differs from the package record, and when the repository holds anything that is not the
  package's.
- **`check`** compares the Hub with the package record by name, size, and hash, runs the
  card's code by repository name, and writes `reports/packaging/publish_record.json` and
  `.md`. A public repository is checked with no token at all.

No code makes a repository public, deletes one, or edits a file on the Hub; a guard test
scans for those calls.

## Issues resolved

- **A check "without a token" could have used a saved login.** The client is built with no
  token at all, and the process that runs the card's code gets
  `HF_HUB_DISABLE_IMPLICIT_TOKEN`.
- **The Hub adds `.gitattributes`** to every repository. It is allowed and named in the config.
- **A library's error text can repeat what was sent.** The Hub client reports the error's
  kind and HTTP status only, and everything printed passes through `redact`.

## Notes for the owner

- **Your steps**, in order (runbook section 13):
  1. Put the token in `.env` as `HF_TOKEN=<the token>`.
  2. `venv\Scripts\python -m scripts.hf_publish upload adapter --yes`, then `check adapter`.
  3. `venv\Scripts\python -m scripts.hf_publish upload merged --yes`, then `check merged`.
  4. Read both cards on the Hub; make both public, the merged copy first.
- **`check merged` downloads the 8 GB again** into the Hugging Face cache and runs the model
  twice. Allow for the time and about 8 GB of disk.
- **The first real contact with the Hub is your upload.** Two things can only be seen then:
  how the Hub reports a large file's hash (if it reports none, a file over 50 MB is
  compared by size alone and is not fetched), and what the Hub's card checker says about the header's metric
  names.
- **Nothing is committed.** The working tree holds this version's code and documents.
