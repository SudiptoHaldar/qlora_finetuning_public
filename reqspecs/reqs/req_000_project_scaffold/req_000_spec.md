# Project Scaffold

Spec Group      : req_000_project_scaffold  
Feature Name    : project_scaffold  

I will generate multiple versions of PRPs addressing **project_scaffold** items; I would progressively add details on new/existing items in spec files located in this directory and I'll specify which files to read for which PRP version - the different versions of PRPs would be created by the use of '--version' flag.

Read the following files for generating PRPs  
    - [--version 1] | 
        - **req_000_01_spec.md**: Process bootstrap
    - [--version 2] | 
        - **req_000_02_spec.md**: Package skeleton, settings, CI
    - [--version 3] | 
        - **req_000_03_spec.md**: Local development environment and training stack
    - [--version 4] | 
        - **req_000_04_spec.md**: Run registry and cost ledger
    - [--version 5] | 
        - **req_000_05_spec.md**: AWS foundation

Later versions are listed in `req_000_roadmap.md`; a `[--version N]` entry is added here when its spec file is written.
