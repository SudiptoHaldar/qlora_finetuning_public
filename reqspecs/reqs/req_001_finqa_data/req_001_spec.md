# FinQA Data

Spec Group      : req_001_finqa_data  
Feature Name    : finqa_data  

I will generate multiple versions of PRPs addressing **finqa_data** items; I would progressively add details on new/existing items in spec files located in this directory and I'll specify which files to read for which PRP version - the different versions of PRPs would be created by the use of '--version' flag.

Read the following files for generating PRPs  
    - [--version 1] | 
        - **req_001_01_spec.md**: Dataset snapshot and schema report
    - [--version 2] | 
        - **req_001_02_spec.md**: Frozen split manifest
    - [--version 3] | 
        - **req_001_03_spec.md**: Canonical serialization
    - [--version 4] | 
        - **req_001_04_spec.md**: Token budget report

Later versions are listed in `req_001_roadmap.md`; a `[--version N]` entry is added here when its spec file is written.
