# DSL Evaluation

Spec Group      : req_002_dsl_evaluation  
Feature Name    : dsl_evaluation  

I will generate multiple versions of PRPs addressing **dsl_evaluation** items; I would progressively add details on new/existing items in spec files located in this directory and I'll specify which files to read for which PRP version - the different versions of PRPs would be created by the use of '--version' flag.

Read the following files for generating PRPs  
    - [--version 1] | 
        - **req_002_01_spec.md**: DSL parser and safe executor
    - [--version 2] | 
        - **req_002_02_spec.md**: Metrics and gold self-check
    - [--version 3] | 
        - **req_002_03_spec.md**: Evaluation runner

Later versions are listed in `req_002_roadmap.md`; a `[--version N]` entry is added here when its spec file is written.
