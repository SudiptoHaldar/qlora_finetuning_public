# Comparison

Spec Group      : req_005_comparison  
Feature Name    : comparison  

I will generate multiple versions of PRPs addressing **comparison** items; I would progressively add details on new/existing items in spec files located in this directory and I'll specify which files to read for which PRP version - the different versions of PRPs would be created by the use of '--version' flag.

Read the following files for generating PRPs  
    - [--version 1] | 
        - **req_005_01_spec.md**: Test unlock and six-arm evaluation
    - [--version 2] | 
        - **req_005_02_spec.md**: Cost model
    - [--version 3] | 
        - **req_005_03_spec.md**: Comparison report

Later versions are listed in `req_005_roadmap.md`; a `[--version N]` entry is added here when its spec file is written.
