## Summary

The AWS resources were created and verified on 2026-11-14. This PRP adds the code and
documentation: a YAML file naming the resources, a read-only script that prints PASS or FAIL
for seven checks (identity, bucket, two roles, GPU quota, Nova models, budget) and exits
non-zero on any failure, unit tests that need no network or credentials, and a runbook section
with teardown steps.

The spec depends on v0.02, which is not built. The PRP therefore builds v0.05 self-contained:
the script loads its own YAML, only the `network` pytest marker is registered, ruff runs with
default rules, and no `qlora_finetuning/` package is created. v0.02 later swaps the loader for
`load_config()`.
