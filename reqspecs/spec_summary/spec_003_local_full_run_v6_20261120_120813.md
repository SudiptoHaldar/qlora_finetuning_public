## Summary

The local full run needs no change to training, scoring, or selection. This PRP adds what a
five-hour laptop run needs around it. A preflight checks the plan, a clean tree, free GPU
memory, disk, power, and that nothing is running or waiting to be resumed. A status command
says how far a run is and how long it has left. A local note is the committed record of the
run: hours, speed, peak memory, the per-checkpoint table on quick-dev, the selected
checkpoint and its result on dev, and the categories of its failures, with a
local-against-cloud section once the cloud selection exists. The note is a separate file,
labelled "not an arm of the comparison", and nothing reads it as a selection.

The agent does not start the run: the owner does. Nothing is billed and no AWS call is made.
The decisions of spec section 8 are taken as recommended.
