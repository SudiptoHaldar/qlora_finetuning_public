## Summary

`python -m qlora_finetuning.demo` reads a question, a table, and optional context from a
JSON file, asks the Qwen model with the selected adapter on the local GPU, and prints the
proposed program, each step's value, the executed result, and whether the model's own
answer agrees with it. With no argument it answers one invented sample.

Nothing new is built for the model, the prompt, the reply, or the comparison: the prompt
comes from the serializer, the model is asked through `QwenPredictor`, the reply goes only
to `run_reply`, and the one comparison is a new function in the metrics. The demo starts
no run, writes no file, calls no AWS service, and reads no dataset row.

The five decisions of spec section 8 are taken as recommended, because the owner started
the PRP: Qwen only, a warning for an over-length input, no record of a demo call, a JSON
file as input, and a stop with the pull command when the checkpoint is absent.
