## Summary

One command makes a copy of a commit that can be published as
`SudiptoHaldar/qlora_finetuning_public`: no history, the folders the owner named left
out, the AWS account number replaced by `123456789012`, the private repository's name
replaced by the public one, the runbook at `docs/runbook.md`, and a notice that the copy
is a redacted snapshot. A second command proves that nothing private remains and runs
lint and the test suite inside the copy.

The tool makes no commit, no push, and no network call. The copy's tests that verify the
configuration freeze are skipped there by a marker, and say so in the test output.

## Confidence score
