## Summary

One command uploads the two package folders of v6.02 to private repositories on the
Hugging Face Hub, after comparing every file with the package record. A second command
compares what is on the Hub with that record by name, size, and hash, and runs each card's
code by repository name. The token is read from `.env`, is never a command-line argument,
and is never printed or recorded. No command makes a repository public: the owner does
that on the Hub, after reading the rendered cards.

The uploads are the owner's. Claude builds and tests the tool, runs `plan`, and runs the
final check once both repositories are public, which needs no token.
